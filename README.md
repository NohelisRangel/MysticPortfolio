# MysticPortfolio
The personal portfolio of Nohelis Rangel, frontend developer and UI designer, mapped onto a birth chart. Built with React and Vite: Sun, Moon and Rising cards introduce who I am, skills appear as constellations, and 12 projects live in the 12 zodiac Houses. Responsive, accessible and easy to update.


This is my personal portfolio, designed as a map of the night sky. I’m a frontend developer and UI designer, and I built this site to show both sides of my work: the design thinking and the code behind it.
The site is shaped like a birth chart. My Sun, Moon and Rising signs introduce what I do, what drives me and how I collaborate. My skills are drawn as constellations: frontend, design and tools, each a group of connected stars. My projects are laid out as the 12 Houses of the zodiac, each with its own preview screen, tech stack and links.
It’s built with React and Vite, with responsive layouts, accessible markup and hand-written CSS. All the content lives in one file (src/data/content.js), so updating projects, skills or experience never means touching the components.
